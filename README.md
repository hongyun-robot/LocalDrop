# LocalDrop

一个无需登录的局域网文件、图片和文本快传工具。手机与电脑打开同一个 LocalDrop 地址后，会自动出现在彼此的设备列表中。支持 WebRTC 的浏览器会在设备间直连；WebRTC 被浏览器策略或运行环境禁用时，会自动改用局域网 WebSocket 中继，内容不会落盘保存。

## 本地开发

```bash
npm install
npm run dev
```

终端会同时显示本机地址和局域网地址，例如 `http://192.168.1.10:4173`。电脑打开本机地址，其他手机或电脑连接同一 Wi-Fi / 局域网后打开局域网地址即可互相发现。

## 生产运行

```bash
npm run build
npm run preview
```

默认监听 `0.0.0.0:4173`，也可以用环境变量覆盖：

```powershell
$env:PORT=8080
npm run preview
```

首次运行时，如果系统询问是否允许 Node.js 通过防火墙，请允许“专用网络”，否则其他局域网设备可能无法访问。

## 已实现

- 自动发现同一 LocalDrop 服务中的在线设备
- 自定义并在本机保存设备名称
- 文本发送与一键复制
- 多文件 / 图片选择、拖放与批量发送
- 文件名称、大小、类型展示与接收下载
- 实时进度、传输速度与完成状态
- 浅色 / 深色皮肤切换，并记住本机选择
- 响应式手机 / 电脑界面
- 无账号、无内容落盘

当前版本按需求不包含断点续传和自动重试。接收文件暂存在浏览器内存中，超大文件的实际上限取决于接收设备的可用内存。
